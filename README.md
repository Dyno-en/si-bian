# si-bian

把模糊想法一个词一个词推到有边界。用户有一个说不清的想法、理论或问题，想搞清楚本质、找到边界、检查前人理论支持时使用。不直接给答案，不做文案写作，不做内容检测。

## 安装

```bash
npx -y skills add Dyno-en/si-bian -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $si-bian 完成它所解决的任务。

## 运行依赖

- 支持 Agent Skills 的客户端

## 内容

本仓库只发布运行这个 Skill 所需的文件。本地评测样本、预期答案和运行记录不包含在公开包中。
